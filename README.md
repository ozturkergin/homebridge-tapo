# Homebridge Tapo Ergin

This is a local, customized copy of the original [homebridge-kasa-python](https://github.com/ZeliardM/homebridge-kasa-python) repository, tailored for local use and support of specific Tapo/KLAP devices (such as L630 bulbs).

## Overview

This Homebridge plugin allows you to control TP-Link Kasa and Tapo devices within Apple HomeKit. It retains the core architecture of the original `homebridge-kasa-python` plugin, particularly utilizing the robust `python-kasa` backend to ensure full compatibility with newer devices that rely on the Tapo/KLAP protocols.

For full original documentation, configuration instructions, and support, please refer to the original repository.
